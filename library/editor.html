🔑 Kết nối GitHub để lưu

Trang này lưu bằng cách commit thẳng vào repo qua GitHub API. Token chỉ được lưu trong trình duyệt của máy này, không gửi đi đâu ngoài api.github.com.

  1. Mở tạo fine-grained token.
  2. Repository access: Only select repositories → chọn repo của trang này.
  3. Permissions → Repository → Contents: Read and write. Không cần quyền nào khác.
  4. Tạo token rồi dán vào ô dưới.
